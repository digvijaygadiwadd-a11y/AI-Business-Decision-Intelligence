# AI Business Decision Intelligence Platform

An enterprise decision intelligence and analytics workspace featuring secure database-driven authentication, dynamic dataset profiling, and multi-agent natural language analysis.

## Core Scope & Known Limitations
* **Real Features:** Secure database login (JWT + bcrypt), interactive data visualization via Recharts, CSV/Excel dataset ingestion, and SQLite persistence.
* **Known Limitations:** The natural language analysis layer relies on deterministic analytical routines and structured data mapping rather than fully autonomous large language models. Dataset uploads currently store summaries for reporting, and advanced multi-agent orchestrations operate within configured rule-based constraints.
